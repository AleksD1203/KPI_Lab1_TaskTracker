## Документація застосунку

### Призначення
Веб-застосунок для керування списком завдань. Дозволяє створювати задачі, переглядати їх та змінювати статус на "виконано".

### API Ендпоінти
* `GET /` — (Тільки HTML) Список усіх ендпоінтів бізнес-логіки.
* `GET /tasks` — Список усіх задач. Підтримує заголовок `Accept`: `text/html` (таблиця) або `application/json`.
* `POST /tasks` — Створення нової задачі (JSON: `{"title": "..."}`).
* `POST /tasks/<id>/done` — Зміна статусу задачі на "done".
* `GET /health/alive` — Перевірка стану (завжди повертає OK).
* `GET /health/ready` — Перевірка готовності (підключення до БД).

## Інструкція з тестування

Для перевірки коректності системи виконано:

1. **Systemd Socket Activation:** Перевірено статус сокета (`systemctl status mywebapp.socket`). Сервіс активується автоматично при зверненні до порту.
2. **Безпека Nginx:**
   * Запит `curl http://127.0.0.1/health/alive` повертає `403 Forbidden` (доступ до службових ендпоінтів ззовні заблоковано).
   * Запит `curl http://127.0.0.1/tasks` працює успішно.
3. **Логування:** Перевірено наявність записів у `/var/log/nginx/mywebapp_access.log`.
4. **Файл Gradebook:** Перевірено файл `/home/student/gradebook`, що містить число 4.
5. **Бізнес-логіка:**
   * Створення задачі через POST.
   * Оновлення статусу через POST `/tasks/<id>/done`.
   * Отримання результатів у HTML та JSON.
